# 详情页响应式设计规范（CarAppStore / 青柠应用商店）

> 状态：**设计蓝图 v1.1** —— 面向紧凑、中等、扩展三档窗口的文字版准绳。
> 范围：仅应用详情页（Detail）。承接《首页响应式设计规范》的令牌与三档窗口布局规则。
> 风格基线：青柠绿（lime/fresh）+ 薄荷淡底 + 白色圆角卡片，与首页完全一致。
> **本页核心命题**：当前代码已按 `supportedPlatforms/currentPlatform` 分流主动作；本规范继续补齐平台标签和响应式视觉表达。

## 0. 设计令牌（复用首页，仅列详情页差异）

令牌全集见《首页响应式设计规范》§0，**三档窗口共用、不重定义**。详情页新增/强调的少量语义：

### 0.1 详情页专属语义色

| Token | 值 | 用途 |
|---|---|---|
| `--platform-active` | `--brand` `#2DBE6B` | "支持设备"中**本机可装**平台标签：高亮实底 |
| `--platform-other` | `--text-hint` `#9AA8A0` | 其他平台标签：灰显，仅展示不可点 |
| `--platform-blocked` | `--disabled` `#C9D3CD` | 当前设备不支持整应用时的主按钮态 |

### 0.2 复用要点（不重列，强调纪律）

- 主按钮 = `--brand` 实心、圆角胶囊、高 54–58（与现有 `btnPrimaryAction` 58dp 一致）。
- 区块标题 = 18/700（跨页不漂）；应用名 H2 = 16/600。
- 间距/圆角/阴影/触控目标：完全复用首页 §0.3 / §0.4。
- 可选车载发行目标可把触控目标提升到 ≥60×60；该要求不进入通用 Android 默认门禁。

## 1. 三档窗口布局规则（复用首页 §1）

| 形态 | 导航 | 内容列 | 备注 |
|---|---|---|---|
| **手机** | 顶部返回栏 + 底部胶囊 Tab（可选隐藏） | 单列滚动 | 详情页通常**隐藏底部 Tab**，主操作吸底（见 §2.1） |
| **平板** | 同手机（或常驻底 Tab） | 单列（限宽约 560 居中） | 大屏下内容限宽，避免行长过长 |
| **扩展窗口/桌面级大屏** | 左栏（复用首页侧栏） | 中栏详情 + **右栏**（任务状态/相关推荐） | 复用现有 `layout-sw900dp-land`；右栏承载“任务状态面板” |

> 断点纪律同首页：导航在断点整体切换，不混用。

## 2. 详情页区块蓝图（Screen Blueprint）

### 2.1 手机端（单列 + 吸底主操作）

```
[状态栏 62] 系统接管
──────────────
[顶部返回栏]  左：关闭/返回箭头  中：（无标题，省空间）  右：分享 / 更多(⋯)
──────────────
[应用信息卡 / 白卡 圆角16 阴影]
   图标 72×72 圆角16 ─ 名称 H2 16/600
                       开发者 + 评分 ⭐4.8 · 下载量 1.2亿
   [支持平台标签行]  Android(高亮) · iOS(灰) · macOS(灰) · Windows(灰)
[任务状态面板 / 浅卡]
   版本 8.2.0 · 大小 86MB · 更新于 07-15 · 年龄分级 3+
   （安装态时显示：已安装 / 可更新 v8.3.0）
[截图画廊]  横向滚动 3–5 张 圆角12，间距12，首图留左安全边
[简介区块]  标题「简介」+ 折叠正文（默认3行，超长「展开」）
[版本/权限区块]  标题「权限」+ 权限列表(定位/存储/通知…) + 「查看全部权限」
[相关推荐]  标题「猜你喜欢」+ 横向应用卡 ×5
[底部吸底操作条]  主按钮(满宽) + 右侧「我的应用」次按钮
```

- **主操作吸底**：详情页主按钮固定在底部（非 Tab 占用区），距底 12；滚动时内容在按钮上方留 12 底距。
- 顶部返回栏**不吸顶**（简单返回即可）；若含分段控件再考虑吸顶。
- 单纵向滚动容器。

### 2.2 平板端（限宽居中）

- 内容限宽 ≈ 560，居中；应用信息卡与任务状态面板可并排（卡左 / 状态右）以压缩首屏。
- 截图画廊、简介、权限、推荐同手机区块序列。

### 2.3 扩展窗口（中栏 + 右栏）

- **中栏**：同手机内容序列（应用信息卡 → 任务状态 → 截图 → 简介 → 权限 → 推荐）。
- **右栏（任务状态面板迁移至此）**：① 当前应用任务状态卡（下载进度/已安装/可更新）；② 同类推荐 Top3 缩略。主操作仍在中栏底部吸底或右栏底部。
- 可选车载发行目标可在扩展窗口上追加驾驶状态交互限制；通用版本不根据驻车状态删减内容。

## 3. 跨平台分流状态机（本页核心，必须落地）

> 背景：当前仓库是 **Android 客户端**，只能下载/安装 Android 包。代码已建立 `AppPlatform`、`ClientPlatformCapabilities`、`UNSUPPORTED` 动作和业务执行层硬拦截。

### 3.1 支持设备标签规则

- 标签行枚举该应用**声明支持**的全部软件平台（来自 `supportedPlatforms`）；手机、平板、大屏和车载是设备形态，不进入平台枚举。
- **本机可装平台**（Android，且当前客户端即 Android） → `--platform-active` 高亮、实底、可点（点开跳商店/复制链接）。
- **其他平台** → `--platform-other` 灰显、仅展示、不可点；提示文案「可在其他设备查看」。
- 服务端未返回平台元数据时，标签行降级为单行「Android」并默认本机可装。

### 3.2 主操作按钮状态矩阵（按"当前平台 vs 支持列表"）

| 条件 | 主按钮文案 | 按钮态 | 次级动作 |
|---|---|---|---|
| 本机 Android ∈ 支持列表，且未安装 | **立即下载** | `--brand` 实心 | — |
| 本机 Android ∈ 支持列表，下载中 | 进度环 + `下载中 63%` | 描边 + 暂停图标 | 点击暂停 |
| 本机 Android ∈ 支持列表，已暂停 | **继续** | 描边 brand | 点击继续 |
| 本机 Android ∈ 支持列表，已安装 | **打开** | 描边 brand | 跳「我的应用」 |
| 本机 Android ∈ 支持列表，可更新 | **更新** | `--brand` 实心 | 显示新版本号 |
| 本机 Android ∉ 支持列表（应用仅 iOS/Mac…） | **当前设备不支持** | `--platform-blocked` 置灰禁用 | 「发送到其他设备」「复制下载链接」 |
| 下载失败 | **重试** | `--danger` 描边 | 显示失败原因（存储不足/网络） |

> 严禁：把 iOS/Mac/Windows 包做成可点击下载。非本机平台的"下载"一律置灰或改为"发送/复制链接"。

### 3.3 下载/安装完整状态机（与首页、下载管理共享）

```
下载中 →(暂停)→ 已暂停 →(继续)→ 下载中
  ↓(完成)         ↓(失败)
已完成 → 安装中 → 已安装 →(有新版)→ 可更新
  ↓(失败)                          ↓(更新)
失败(原因+重试)                    更新中 → 已安装
```

- 失败态必须带**原因 + 重试入口**（概念稿缺失）。
- 安装中/安装失败态必须存在（概念稿直接跳"打开"，缺失）。

## 4. 组件规范（详情页专属）

### 4.1 应用信息卡（App Info Card）
- 72×72 图标（圆角16） + 名称(16/600) + 开发者/评分/下载量(13 次级)。
- 组件内不得再加水平内边距，由 wrapper 统一给。

### 4.2 任务状态面板（Task Status Panel）
- 浅卡（`--brand-soft` 底或白卡描边），键值对：版本 / 大小 / 更新日期 / 分级。
- 安装态时整块替换为进度或"已安装"指示。

### 4.3 主操作按钮（Primary Action，吸底）
- 满宽、高 54（通用窗口）；可选车载发行目标可提升到 64，圆角胶囊、`--brand` 实心。
- 文案与态严格按 §3.2 矩阵切换；禁用态用 `--platform-blocked`。

### 4.4 截图画廊（Screenshot Gallery）
- 横向滚动，卡片 180×320（手机）圆角12，间距12；首图左对齐留安全边。
- 占位图用 `--brand-soft` 底 + 简笔图标，避免 AI 风格漂移（同首页 Banner 纪律）。

### 4.5 权限列表（Permission List）
- 每项：线性图标 20 + 权限名(13) + 说明(11 次级)；最多首屏展示 3 项，「查看全部」展开。

### 4.6 相关推荐卡（Related Card）
- 复用首页「应用横卡」组件（§3.2），横向 ×5。

## 5. 状态与空态清单（详情页必做）

| 状态 | 表现 |
|---|---|
| 加载中 | 应用信息卡 + 画廊区骨架屏（同形灰块呼吸），非整页转圈 |
| 无网络 | 顶部条提示 + 重试；已缓存内容可看，下载按钮禁用并提示「网络不可用」 |
| 应用下架/不存在 | 整页占位「该应用已下架」+ 返回首页 |
| 当前设备不支持 | 主按钮置灰「当前设备不支持」+ 次级「发送/复制链接」（见 §3.2） |
| 下载失败 | 按钮「重试」+ 原因条（红字 `--danger`） |
