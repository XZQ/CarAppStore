# 首页响应式设计规范（CarAppStore / 青柠应用商店）

> 状态：**设计蓝图 v1.1** —— 面向紧凑、中等、扩展三档窗口的文字版准绳。
> 范围：仅首页（Home）。后续详情页、下载管理、升级页按同模板扩展。
> 风格基线：青柠绿（lime/fresh）+ 薄荷淡底 + 白色圆角卡片，延续 `docs/设计/` 8 张概念稿的视觉方向。
> 产品边界：三档窗口是当前 Android 客户端的响应式布局，不是三个独立平台；车载形态只作为扩展窗口的可选专项。

---

## 0. 设计令牌（Design Tokens）

所有界面共用一套 token；三档窗口只改“布局/栅格/触控目标”，不改 token。建议后续与各模块 `res/values/colors.xml`、`dimens.xml` 逐项对齐（见 §6）。

### 0.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#2DBE6B` | 主品牌色 / 主按钮 / 激活态 / 下载进度 |
| `--brand-strong` | `#16A34A` | 按压态、强调文字 |
| `--brand-soft` | `#E7F8EF` | 图标底座、选中底色、徽标浅染 |
| `--brand-tint` | `#F2FBF6` | 页面薄荷淡底（替代纯白大面积背景，降低刺眼） |
| `--text-primary` | `#16201B` | 主标题/正文重点（带绿调近黑，非纯黑） |
| `--text-secondary` | `#5C6B63` | 描述、次级文字 |
| `--text-hint` | `#9AA8A0` | 占位、禁用、辅助说明 |
| `--surface-card` | `#FFFFFF` | 卡片底 |
| `--surface-page` | `#F2FBF6` | 页面背景 |
| `--border` | `#E4ECE7` | 描边、分割线 |
| `--success` | `#2DBE6B` | 完成 |
| `--warning` | `#F5A623` | 等待/低速/提醒 |
| `--danger` | `#F5455C` | 失败、删除、错误 |
| `--disabled` | `#C9D3CD` | 不可点态 |
| 对比度校验 | 正文/底 ≥ 4.5:1；大字 ≥ 3:1 | 户外强光及可选车载目标需专项复测 |

### 0.2 字阶（Chinese：PingFang SC / 苹方 / 微软雅黑；西文：Inter）

| 角色 | 字号 | 字重 | 行高 | 示例 |
|---|---|---|---|---|
| Display 店名 | 22 | 700 | 28 | 青柠应用商店 |
| H1 区块标题 | 18 | 700 | 24 | 今日推荐 |
| H2 卡片标题 | 16 | 600 | 22 | 应用名 |
| Body 正文 | 15 | 400 | 22 | 描述文案 |
| Secondary 次文 | 13 | 400 | 18 | 下载量/评分 |
| Caption 标注 | 11–12 | 500 | 16 | 标签、单位 |

> 规则：所有"区块标题"字号必须一致（18/700），跨页不漂移；同一屏内最多 2 个层级字重（400 + 700）。

### 0.3 间距（基准 4px，与 `dimens.xml` 的 spacing_* 对齐）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`

| 场景 | 值 |
|---|---|
| 页面左右内边距（wrapper） | 16（手机）/ 20（平板）/ 24（桌面） |
| 区块间距（gap） | 24（主区块）/ 12（区块内紧邻项） |
| 卡片内边距 | 16 |
| 列表项竖向间距 | 12 |
| 底部安全区 | 跟随系统；Tab Bar 自身含 21 下边距 |

### 0.4 圆角 / 阴影 / 触控

| Token | 值 |
|---|---|
| 圆角 sm / md / lg / xl | 8 / 12 / 16 / 24 |
| 胶囊（Tab / 按钮 / 徽标） | 999 |
| 卡片阴影 | `0 2px 8px rgba(22,32,27,.06)`（轻，不抢内容） |
| 最小触控目标 | 通用窗口 ≥ 44×44；可选车载发行目标建议 ≥ 60×60 |

## 1. 三档窗口布局规则（响应式断点）

| 形态 | 画布尺寸（建议） | 导航 | 内容列 | 特殊轨道 |
|---|---|---|---|---|
| **手机** | 393 × 852 | 底部胶囊 Tab Bar（4 项） | 单列 | 状态栏 62px，顶部下沉 header |
| **平板** (sw600dp) | 834 × 1112 | 底部胶囊 Tab Bar（可 4–5 项，更宽） | 双列 | 同一区块内双列排布 |
| **扩展窗口/桌面级大屏** (sw900dp-land) | 1280 × 800（横） | 左侧栏（主+发现分组） | 中栏单/双列 + **右栏任务摘要** | 沿用现有 `layout-sw900dp-land` 结构（左菜单/中内容/右任务摘要） |

> 断点纪律：导航形态在断点处整体切换（底 Tab → 侧栏），不要混用；内容列在 sw600 起双列，sw900 起加右栏。

## 2. 首页区块蓝图（Screen Blueprint）

### 2.1 手机端（单列，自上而下）

```
[状态栏 62] 系统接管，时间/信号/电量，内容不压它
──────────────
[Header 下沉区]
  左：店名「青柠应用商店」(Display 22/700)
  右：搜索胶囊(占满余下宽度) + 下载入口图标(带角标 badge)   ← 本规范新增（见 §5 对照）
[Banner 英雄卡]  「春日焕新季」插画卡 高 140 圆角16
[快捷入口行]  5 项：分类/排行/必备/活动/专题（图标底座48 + 标签11）
[区块 今日推荐]  标题 + 「查看更多」→ 3 条应用列表行
[区块 热门游戏]  标题 + 横向滚动卡片 ×5（图标/名/下载按钮）
[区块 热门软件]  标题 + 横向滚动 ×5
[区块 编辑推荐]  一张大特性卡（Notion 风）
[区块 限时活动]  banner 卡（周末狂欢）
[底部胶囊 Tab Bar] 首页(激活)/游戏/软件/我的
```

- 滚动：单一纵向滚动容器；Header 在首屏内，不强制吸顶（吸顶仅用于分段控件场景）。
- 下载按钮默认可见，不藏进二级页。

### 2.2 平板端（双列）

- 同一组区块，进入双列：
  - 今日推荐（左列 3 行列表）｜ 热门游戏（右列横卡）
  - 热门软件（左）｜ 编辑推荐（右）
  - 限时活动 banner 跨满宽
- 快捷入口扩为 8 个（加 专题/儿童）两行。
- 底部 Tab Bar 保留，项可 4–5。

### 2.3 扩展窗口（左栏 + 中栏 + 右栏）

- **左栏（Sidebar）**：主导航 `首页/游戏/软件/下载管理/我的` + 分隔 + 发现分组 `分类/排行/活动`。下载管理带实时角标。
- **中栏**：同手机的内容序列，但区块内双列。
- **右栏（任务摘要）**：① 今日推荐 Top3 缩略；② **下载任务摘要卡**（进行中 N / 已完成 M，点开进下载管理）——强化"下载是核心任务"的跨端一致性（见 §5）。

> 可选车载发行专项：可在扩展窗口布局上追加驾驶状态交互限制和 ≥60dp 触控目标，但不得作为手机、平板或普通大屏版本的默认行为。

## 3. 组件规范（可复用于三档窗口）

### 3.1 应用列表行（App List Row）—— 今日推荐用
- 结构：`图标 48×48 圆角12` + `名称 H2 16/600` + `描述 Body 13 次级（一行截断）` + `右侧「下载」按钮(胶囊, brand)`
- 竖向间距 12；点击整行进详情。
- 下载按钮三态：可下载(brand 实心) / 下载中(显示进度环+暂停) / 已安装(描边「打开」)。

### 3.2 应用横卡（App Card）—— 热门游戏/软件用
- 结构：`图标 64×64 圆角14` 居中 + `名称 13/600 居中(限1行)` + `「下载」小按钮`
- 卡片宽 ≈ 96，横向滚动，卡片间距 12。

### 3.3 Banner 英雄卡
- 高 140（手机）/ 160（平板+），圆角 16，左右内边距 18。
- 文案：主标题 Display 22/700 + 副标 Body 13 次级 + 一个动作胶囊。
- 视觉：统一**插画系**（3D 植物/礼盒同族），禁用与游戏 keyart 混搭。占位图用 `--brand-soft` 底 + 简笔图标，避免 AI 生成导致的风格漂移。

### 3.4 快捷入口（Quick Entry）
- 图标底座 48×48 圆角 12，`--brand-soft` 底 + 线性图标；下方标签 11/500 居中。

### 3.5 底部胶囊 Tab Bar（手机/平板）
- 容器：全宽，下边距 21（含 home indicator 安全区）；胶囊高 62，圆角 36，1px 描边。
- 项：图标 18 + 标签 10/600 大写（中文不强制大写，但保持统一字重）；激活项 `brand` 实心底+反白，非激活透明+次级色。最多 5 项。

### 3.6 角标 Badge（下载入口/侧栏）
- 小红点/数字：直径 16，`--danger` 或 `--brand` 实心，白字 10/700；仅显示 >0，0 时隐藏。
- **跨端一致**：同一未完成任务数在手机 Header、平板 Header、桌面侧栏必须一致（杜绝概念稿里 1/2/3 乱跳）。

## 4. 状态与空态清单（首页必做）

| 状态 | 表现 |
|---|---|
| 加载中 | 区块骨架屏（同形状灰块 `--border` 呼吸动画），非整页转圈 |
| 无网络 | 今日推荐区替换为「网络开了小差」+ 重试 |
| 空（无推荐） | 插画占位 + 「暂无内容，去逛逛」引导 |
| 下载进行中 | Header/侧栏角标实时 +1，按钮转「下载中」态 |
| 角标归零 | 数字角标隐藏，保留图标 |

## 5. 与现有实现对照（mockup ↔ XML）

> 来源：`app/src/main/res/layout/activity_main.xml`、`feature-home/.../layout/fragment_home.xml`

| 项 | 现有实现 | 本规范 | 处置 |
|---|---|---|---|
| 底部 Tab | 首页/游戏/软件/我的应用（4 项）✓ | 首页/游戏/软件/我的 | **一致**，标签统一为「我的」 |
| 按钮 ID 遗留 | `btnNavSearch` 显「游戏」、`btnNavDownload` 显「软件」 | — | 实现侧改名：`btnNavGame`/`btnNavSoftware` |
| 首页 Header | 店名+搜索+政策条，无下载入口 | **新增下载入口+角标** | 实现需加 Header 下载图标并接任务数 |
| 快捷入口 | 4 个：分类/排行/必备/厂商专区 | 手机 5 个（含 活动） | 统一为通用“专题/厂商专区”，车载 OEM 专区仅在对应发行目标出现 |
| 首屏区块 | 今日推荐/排行/游戏/新游预约/限时活动 | 今日推荐/热门游戏/热门软件/编辑推荐/限时活动 | 取并集：保留排行、新游预约；补 热门软件、编辑推荐 |
| 桌面右栏 | 现有 sw900dp-land 已有「右任务摘要」 | 右栏接「下载任务摘要」 | 直接复用现有右栏结构，填充下载态 |

> 结论：规范以概念稿为愿景、以现有实现为底盘，**不推翻已上线结构**，只补"下载常驻入口 + 角标一致性 + 缺失区块"。

## 6. 落地动作（供后续）

1. **Token 对齐**：把 §0 的色值/间距补进 `colors.xml` / `dimens.xml`（已有 spacing_*，核对是否覆盖 20/24/40）。
2. **画布上稿**（画布恢复后）：依 §2 三档窗口结构 + §3 组件，在 Ardot 画布重建；本文件即上稿清单。
3. **实现改造**：按 §5 对照表改 `fragment_home.xml` 与 `activity_main.xml`，新增 Header 下载入口与角标绑定。
4. **评审门控**：完成后走质量审查（哲学/层次/执行/特异性/克制 5 维）再导出。
