# CarAppStore Docs

跨平台应用分发与管理 App 的项目文档目录。当前仓库是 Android 客户端实现；车载 OEM 是可选平台适配，不是产品主线。

所有文档先遵循 **[00-产品定位与平台边界](./00-产品定位与平台边界.md)**。历史文件名中的“车况”“OEM”用于兼容既有链接，不代表项目是车端 App。

## 工程约束

- MVVM，手动 DI（AppContainer），FragmentManager 导航
- 不使用 Hilt / Navigation
- 业务层固定 7 个核心模块：download / install / upgrade / appmanager / state / policy / repository
