# 31. UI 补全与下载联调实施计划（专家团梳理结论）

> 目标：把 CarAppStore 的业务主链路按 `docs/设计` 的视觉语言落地为完整可跑的"下载→安装"应用商店；用本地模拟目录 + 本地静态服务器驱动真实业务层，不依赖真实后端。
> 阶段：本文件为"先梳理、搞清楚"阶段产物；**实施在用户确认后开始**。

---

## 一、专家团结论摘要

### 1.1 设计分析（8 张设计稿 + docs/27）
- **三端壳层**（docs/27 资源限定符断点）：
  - 手机 `layout/`：顶部品牌区 + 主内容 + 底部 4 项导航（首页/游戏/软件/我的），单列卡片。
  - 平板 `layout-sw600dp/`：双列卡片，仍底部 4 项导航。
  - 车机/桌面 `layout-sw900dp-land/`：左侧完整菜单 + 中央内容 + 右侧常驻任务摘要，大字号、大触控目标。
- **视觉语言**（青柠/抖音/清新应用商店参考）：清新卡片风、主操作按钮显眼；首页 Banner+编辑精选+分类入口；应用卡片含 icon/名称/标签/评分；详情页截图画廊+权限+版本+主按钮；下载管理为列表+进度条+暂停/继续/取消/重试；应用更新为可升级列表+批量升级。
- **当前状态**（docs/27）：首页/下载/升级/详情已具备三端响应式结构，下一步重点是真机像素验收、触控距离校准、真实素材裁切兜底。

### 1.2 架构现状（7 业务域 → UI 映射，专家B）
- 8 个 Fragment（Home/Detail/Search/MyApp/DownloadManager/InstallCenter/Upgrade/Debug）均已有 Fragment+ViewModel+UiState 且真实渲染，**不是空壳**。
- **主要缺口**（非页面缺失，多为数据/策略层未收口）：
  1. 策略拦截无独立提示页（仅内联 `tvPolicyPrompt` 文字）。
  2. 首页/搜索为硬编码假数据，未接 CatalogPage 聚合。
  3. `RealAppRepository` 仍走 raw/回退示例数据。
  4. OEM 车况信号为 `StaticVehicleStateSignalProvider` 占位。
  5. 下载暂停非协程级硬中断（UI 语义 gap）。
  6. 跨页状态联动靠 StateCenter 轮询，实时性无保证说明。
- **结论**：页面骨架齐全，缺的是"本地/真实数据接入"与"系统态（空/错/权限/拦截引导）UI"。

### 1.3 产品流程（完整旅程，专家C）
```
启动 → 首页/推荐 → 分类/搜索 → 应用详情 → 点击下载
     → 下载中心(进度/暂停/继续/取消/重试/校验)
     → 安装中心(策略确认→系统确认→进度→结果)
     → 我的应用(已装/升级角标) / 升级中心(批量升级)
```
- **页面/功能完整清单**：壳层导航、首页与推荐、搜索与分类、应用详情、下载管理、安装管理、升级管理、我的应用、设置与开发者、系统态（空/错/权限/引导）。
- **优先级**：P0 串起主流程（壳层+七页+关键系统态）；P1 体验补齐（搜索联想/批量全选/常驻任务摘要/策略信号面板/拦截引导/弱网）；P2 增值（推荐算法位/埋点/灰度UI/多端像素校准）。

## 二、把整个项目串起来的方案（Item 1 + Item 2）

核心思路：**用"本地模拟目录 + 本地静态服务器"驱动真实业务层**，让 UI 跑通完整下载流程，无需真实后端。

1. **抓取 10 个真实 App**（建议 F-Droid 开源应用，直链稳定、无版权风险；豌豆荚反爬且多为闭源，作备选）→ 存入 `local-apks/`。
2. **生成 `local_catalog.json`**：覆盖必填/可选字段、`hasUpgrade`、`rolloutPercent`、`listingState`（含 HIDDEN/ROLLBACK 容错样例）、`searchKeywords`(数组)。
3. **起本地静态服务器**：`python -m http.server` 提供 APK 下载地址（`http://localhost:PORT/...`）。
4. **接 `local-sim` 环境**：在 `DownloadEnvironmentConfig` 增加本地模拟环境，`catalogEndpointUrl` 与下载基地址指向 localhost；`RealAppRepository` 走本地目录，`RealFileDownloader` 真实 HTTP Range 拉 localhost 文件 → 进度/断点续传/校验全为真。
5. **安装**：使用 `PackageInstaller.Session` 触发系统确认；未授予“允许安装未知应用”权限时，任务中心跳转系统设置页。

> 效果：首页浏览 → 点下载 → 下载中心真实进度/暂停/续传/校验 → 安装中心（流程与 UI 占位）→ 我的应用/升级中心，整条主链路在本机端到端跑通。
